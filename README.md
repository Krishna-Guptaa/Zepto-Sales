Worked on a sales analytics project using **Python, Pandas, Numpy, Matplotlib, Seaborn, MYSQL & Dashboarding** to extract meaningful insights from Zepto sales data.

a) **SQL** queries for business insights
b) Sales & Customer trend analysis
c) Performance analysis
d) EDA analysis using **Python**
e) Interactive dashboards for visualisation
